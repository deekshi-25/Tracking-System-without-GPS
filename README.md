# Flask MQTT Dashboard

A simple real-time web application built with Flask, Flask-SocketIO, and MQTT.

## Features
- Receives MQTT messages from a broker
- Displays real-time data in a web interface
- Uses WebSockets for instant updates

## Requirements
- Python 3.x
- Flask
- Flask-SocketIO
- paho-mqtt

## Installation

```bash
pip install flask flask-socketio paho-mqtt

to run: python app.py
